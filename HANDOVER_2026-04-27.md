## Things to NOT do (proven failures)

1. **Don't fine-tune bge-m3** — every variant we tried (4 different translations / data combinations) made recall WORSE than off-the-shelf. The model catastrophically forgets multilingual when fine-tuned on small Swiss corpus (634 clean queries × 5 hard negs = too narrow).
2. **Don't add new citation channels** to the 0.32107 baseline expecting boost — every additive expansion has tested empirically below 0.32107 on Kaggle. The dead-zone effect is real and quantified (val/Kaggle ratio diverges above val ~0.43).
3. **Don't trust val F1 as a leading indicator** above ~0.43 — high val variants (consensus_sweep 0.5261, bold_widebankG 0.5455) score 0.30-0.32 on Kaggle. Val n=10 is too small to discriminate.
4. **Don't submit to public LB to "check"** — the rules in `CLAUDE.md` are explicit about overfitting risk. Each iteration on public score is a leak. We've already burned 5 unnecessary submissions today (each lost vs 0.32107).
5. **Don't use v12_full pipeline for new submissions** — it has `W_RERANK_DOMINATES=True` that corrupts good channels with bad rerank scores. Use additive expansion on the 0.32107 anchor instead. Agent-C confirmed v12_full alone gives val 0.31, below the 0.32107 anchor.
6. **Don't run multiple MPS-heavy jobs in parallel** — a previous parallel-3-agent run had Agent-A kill Agent-B mid-training due to MPS memory contention. Run sequential.

   ```bash
   .venv/bin/python scripts/multi_signal_scorecard.py \
       --val-gold data/val.csv \
       --reference-test submissions/test_submission_baseline_public_best_32107.csv \
       --reference-val submissions/val_pred_baseline_public_best_32107.csv \
       --variant CANDIDATE=submissions/val_pred_CANDIDATE.csv,submissions/test_submission_CANDIDATE.csv
   ```

3. **Promotion gate (advisory):**
   ```bash
   .venv/bin/python promotion_gate.py \
       --candidate-val submissions/val_pred_CANDIDATE.csv \
       --candidate-test submissions/test_submission_CANDIDATE.csv
   ```

4. **Diverse eval (Rust):**
   ```bash
   ./rust/v11_selector/target/release/diverse_eval \
       submissions/val_pred_CANDIDATE.csv \
       submissions/val_pred_baseline_public_best_32107.csv \
       submissions/test_submission_CANDIDATE.csv \
       submissions/test_submission_baseline_public_best_32107.csv
   ```

5. **Decision criteria** (per CLAUDE.md):
   - Val F1 AND LB90 both improved vs 0.32107
   - Per-query F1 std not elevated
   - Pure-additive flag clean (no precision-collapse risk)
   - Jaccard vs 0.32107 anywhere from 0.82 to 0.99 is acceptable
